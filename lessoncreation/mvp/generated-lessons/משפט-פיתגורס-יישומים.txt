[ סעיף ג' - שאלת ברירה יחידה ]

* אפשרות 1: 3² + x² = 4²
* אפשרות 2: 3² + 4² = x² [תשובה נכונה]
* אפשרות 3: (3+4)² = x²
* פתרון מלא: משפט פיתגורס קובע שסכום ריבועי הניצבים שווה לריבוע היתר. הניצבים הם 3 ו-4, והיתר הוא x.

* הנחיה: חשבו את אורך היתר x.
* פתרון מלא: לפי משפט פיתגורס: 3² + 4² = x² => 9 + 16 = x² => 25 = x² => x = 5. אורך היתר הוא 5 ס"מ.

[ סעיף ד' - שאלה פתוחה ]

* הנחיה: כיצד נחשב את אורך הניצב האופקי AC?
* אפשרות 1: על ידי חישוב ההפרש בין שיעורי ה-x של הנקודות A ו-B. [תשובה נכונה]
* אפשרות 2: על ידי חישוב ההפרש בין שיעורי ה-y של הנקודות A ו-B.
* פתרון מלא: אורך קטע אופקי נקבע על פי ההפרש בין שיעורי ה-x של קצותיו.

[ סעיף ג' - שאלת ברירה יחידה ]
=========================================
* סוג השאלה: Single Choice (3 Options)
* הנחיה: איזה חלק במשולש ישר-הזווית ABC מייצג את המרחק בין הנקודות A ו-B?
* אפשרות 1: הניצב AC.
* אפשרות 2: הניצב BC.
* אפשרות 3: היתר AB. [תשובה נכונה]
* פתרון מלא: המרחק בין הנקודות A ו-B הוא הקו הישר המחבר אותן, שהוא היתר במשולש ישר-הזווית ABC.

=========================================
[ סעיף ד' - שאלה פתוחה ]
=========================================
* סוג השאלה: Open Ended
* הנחיה: חשבו את המרחק בין הנקודות A ו-B.
* פתרון מלא: נחשב את אורכי הניצבים:
    אורך הניצב האופקי AC = |x_B - x_A| = |4 - 1| = 3.
    אורך הניצב האנכי BC = |y_B - y_A| = |6 - 2| = 4.
    במשולש ישר-זווית ABC, הניצבים הם 3 ו-4. היתר AB הוא המרחק המבוקש.
    לפי פיתגורס: AB² = AC² + BC² => AB² = 3² + 4² => AB² = 9 + 16 => AB² = 25 => AB = 5.
    המרחק בין הנקודות A ו-B הוא 5 יחידות אורך.

[ סעיף ד' - שאלה פתוחה ]
=========================================
* סוג השאלה: Open Ended
* הנחיה: חשבו את גובה הפרמידה SO.
* פתרון מלא:
    שלב 1: מציאת אורך אלכסון הבסיס AC. הבסיס הוא ריבוע עם צלע באורך 10 ס"מ. במשולש ישר-זווית ABC, AC² = AB² + BC² = 10² + 10² = 100 + 100 = 200. לכן, AC = √200 = 10√2 ס"מ.
    שלב 2: מציאת אורך חצי אלכסון הבסיס AO. O היא מרכז הריבוע, לכן AO = AC/2 = (10√2)/2 = 5√2 ס"מ.
    שלב 3: חישוב גובה הפרמידה SO. במשולש ישר-זווית SOA, הניצבים הם SO ו-AO (5√2 ס"מ), והיתר הוא SA (13 ס"מ).
    לפי פיתגורס: SO² + AO² = SA² => SO² + (5√2)² = 13² => SO² + (25 * 2) = 169 => SO² + 50 = 169 => SO² = 119 => SO = √119.
    גובה הפרמידה SO הוא √119 ס"מ (בערך 10.91 ס"מ).

* סוג השאלה: Open Ended
* הנחיה: חשבו את אורך המוטות התומכים של האוהל.
* פתרון מלא:
    שלב 1: מציאת אורך אלכסון הבסיס AC. הבסיס הוא ריבוע עם צלע באורך 4 מטר.
    במשולש ישר-זווית ABC: AC² = AB² + BC² = 4² + 4² = 16 + 16 = 32. לכן, AC = √32 = 4√2 מטר.
    שלב 2: מציאת אורך חצי אלכסון הבסיס AO. O היא מרכז הריבוע, לכן AO = AC/2 = (4√2)/2 = 2√2 מטר.
    שלב 3: חישוב אורך המוט התומך SA. במשולש ישר-זווית SOA, הניצבים הם SO (גובה האוהל, 3 מטר) ו-AO (חצי אלכסון הבסיס, 2√2 מטר). היתר הוא SA (המוט התומך).
    לפי פיתגורס: SA² = SO² + AO² => SA² = 3² + (2√2)² => SA² = 9 + (4 * 2) => SA² = 9 + 8 => SA² = 17 => SA = √17.
    אורך המוטות התומכים של האוהל הוא √17 מטר (בערך 4.12 מטר).
